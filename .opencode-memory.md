- [2026-10-27] PR #3877 (metrics TLS): el gate "PR Issue Acceptance" de NVIDIA/OpenShell bloquea TODA la matriz de CI para PRs de comunidad si el body no usa "Fixes #NNN"/"Closes #NNN" sobre un issue con label `state:accepted` — "Refs #NNN" NO vale.
