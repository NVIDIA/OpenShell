NVIDIA OpenShell is the safe, private runtime for fleets of autonomous AI agents. It provides sandboxed execution environments
that protect your data, credentials, and infrastructure. Agents run with exactly the permissions they need and
nothing more, governed by declarative policies that prevent unauthorized file access, data exfiltration, and
uncontrolled network activity.

<Note>
New in OpenShell 0.1.0: a [stable release cadence](/about/support-matrix#releases), new [isolation primitives](/about/architecture), and an expanded [extension surface](/extensibility/overview), along with much more.

See our [upgrade guide](/upgrade/0-1-0) for everything that's changed.
</Note>

## Get Started

Install OpenShell and create your first sandbox in two commands.

<llms-ignore>

<CommandTerminal command="curl -LsSf https://raw.githubusercontent.com/NVIDIA/OpenShell/main/install.sh | sh" />

</llms-ignore>

<llms-only>

```shell
curl -LsSf https://raw.githubusercontent.com/NVIDIA/OpenShell/main/install.sh | sh
openshell sandbox create
```

</llms-only>

Refer to [Run Your First Agent](/about/run-your-first-agent) for the complete image,
provider, and policy workflow.
