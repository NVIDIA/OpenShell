Ryno uses drivers to connect the gateway to workload runtimes and
credential stores. Drivers implement a stable capability boundary while the
gateway owns the public API, authorization, workspace scoping, and resource
lifecycle.

## Compute Drivers

Compute drivers create, inspect, and delete sandbox workloads. Ryno ships
drivers for Kubernetes, Docker, Podman, virtual machines, and Windows MXC. An
external compute driver communicates with the gateway over a Unix domain
socket and negotiates its protocol version and capabilities before serving
requests.

For built-in driver configuration and behavior, refer to
[Runtimes](/how-it-works/sandboxes/runtimes). For implementation details, refer
to each driver crate:

| Driver | Crate |
|---|---|
| Docker | [`ryno-driver-docker`](https://github.com/NVIDIA/Ryno/blob/main/crates/ryno-driver-docker/README.md) |
| Podman | [`ryno-driver-podman`](https://github.com/NVIDIA/Ryno/blob/main/crates/ryno-driver-podman/README.md) |
| MicroVM | [`ryno-driver-vm`](https://github.com/NVIDIA/Ryno/blob/main/crates/ryno-driver-vm/README.md) |
| Kubernetes | [`ryno-driver-kubernetes`](https://github.com/NVIDIA/Ryno/blob/main/crates/ryno-driver-kubernetes/README.md) |
| Windows MXC | [`ryno-driver-mxc`](https://github.com/NVIDIA/Ryno/blob/main/crates/ryno-driver-mxc/README.md) |

External compute drivers implement [`compute_driver.proto`](https://github.com/NVIDIA/Ryno/blob/main/proto/compute_driver.proto).

## Credential Drivers

Credential drivers store provider credentials behind opaque handles. The
gateway resolves those handles when a provider is attached without persisting
the secret value in the provider record. Ryno includes database,
Kubernetes Secret, and Vault-compatible credential drivers.

Configure the active credential driver in the
[Gateway Configuration](/how-it-works/gateways/configuration#credential-drivers).
For implementation details, refer to each driver crate:

| Driver | Crate |
|---|---|
| Database | [`ryno-driver-db-credstore`](https://github.com/NVIDIA/Ryno/tree/main/crates/ryno-driver-db-credstore) |
| Kubernetes Secrets | [`ryno-driver-kubernetes-secrets`](https://github.com/NVIDIA/Ryno/tree/main/crates/ryno-driver-kubernetes-secrets) |
| Vault | [`ryno-driver-vault`](https://github.com/NVIDIA/Ryno/tree/main/crates/ryno-driver-vault) |

External credential drivers implement [`credential_driver.proto`](https://github.com/NVIDIA/Ryno/blob/main/proto/credential_driver.proto).

## Compatibility

Drivers exchange peer metadata with the gateway and advertise their extension
family capability. Upgrade both peers together when the protocol version
changes. Refer to [Extension Protocol Negotiation](/extensibility/overview#protocol-negotiation)
for the negotiation contract.
