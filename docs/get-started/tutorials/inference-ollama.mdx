The Ollama community sandbox bundles Ollama and supported coding agents in one
image. Ollama starts inside the sandbox, so it does not require a separate
provider endpoint.

## Create the Sandbox

```shell
openshell sandbox create --from ollama
```

## Use a Model

Run a lightweight local model:

```shell
ollama run qwen3.5:0.8b
```

Or use an Ollama cloud model:

```shell
ollama run qwen3.5:cloud
```

Launch a coding agent with Ollama as its model backend:

```shell
ollama launch claude
ollama launch codex
ollama launch opencode
```

For automation:

```shell
ollama launch claude --yes --model qwen3.5
```

## Host-level Ollama

To share a host-level Ollama server across sandboxes, import a custom provider
profile containing `host.openshell.internal:11434`, the client binary paths,
and the credential binding. Attach that provider to each sandbox and call
Ollama's OpenAI-compatible HTTP endpoint directly.

See [Inference Providers](/sandboxes/inference-routing#configure-a-custom-or-self-hosted-endpoint)
for a complete profile and migration example.

## Troubleshooting

- Run `ollama ps` to confirm the model is loaded.
- Run `ollama pull <model>` if a local model is missing.
- Use `update-ollama` to update Ollama inside a running community sandbox.
- Ollama v0.18 and later requires ROCm 7 drivers for supported AMD GPUs.
